# Enclosed crypto library

This package contains the natives crypto primitives used by the [Enclosed lib and project](https://enclosed.khulnasoft.com). It is a standalone package built to provide compatibility between different environments by exposing the same API for node:crypto and web SubtleCrypto.

## Installation

```bash
# with npm
npm install @khulnasoft.com/crypto

# with yarn
yarn add @khulnasoft.com/crypto

# with pnpm
pnpm add @khulnasoft.com/crypto
```
